# NailExpress

[![Live Demo](https://img.shields.io/badge/Live_Demo-nailxpressng.vercel.app-blue?style=for-the-badge)](https://nailxpressng.vercel.app)

NailExpress is a modern e-commerce web application dedicated to premium press-on nails and beauty accessories. Built with Next.js, it provides an intuitive shopping experience with features like cart management, wishlists, and a streamlined checkout process.

## Features

- **Product Catalog**: Browse our selection of products.
- **Shopping Cart**: Easily add items to your cart and manage quantities.
- **Wishlist**: Save your favorite items for later.
- **Checkout**: Seamless and secure checkout process.
- **Backend / Database**: Powered by Supabase.

## Tech Stack

- **Framework**: [Next.js](https://nextjs.org/)
- **Database / Backend**: [Supabase](https://supabase.com/)

## Getting Started

```bash
npm run dev
# or

# or

# or
```
